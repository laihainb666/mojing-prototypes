# 《墨境：千面残章 · 万具回廊》· 可玩原型

> 十种绘画工具 · 每关一个无法复制的创意 · 画风即规则

这是「万具回廊」设计案的**可玩原型**：在初代「画风侵蚀」渲染内核之上，实现了设计案最核心的增量——
**万具匣工具系统（鼠标作画）**、**按示例关标准手工设计的关卡**、**混合画风章**、**规则突变的惊喜时刻**、
会**夺走你画出的每一笔**的最终 Boss，以及**无尽回廊**随机模式。

## 运行

- **直接双击 `index.html`**（纯静态、零依赖），或 `python -m http.server 8000` 后访问。
- 键盘 + 鼠标操作，建议 Chrome / Edge。

## 操作

| 输入 | 功能 |
| --- | --- |
| A / D · 空格 · Shift | 移动 · 二段跳 · 冲刺 |
| **鼠标左键（按住拖动）** | **按当前工具作画 / 擦除 / 刮削 / 挤喷**（核心操作！） |
| J / K | 工具轻技 / 重技（每种工具完全不同） |
| 1 ~ 4 / Q | 切换携带的四件工具 / 轮换 |
| E | 交互（折叠墙、潜入倒影水潭） |
| H · P · M · 0 | 帮助 · 暂停 · 离开关卡 · 静音 |

## 万具匣：本原型实现的 10 种工具

| 工具 | 战斗 | 解谜 / 关卡互动 |
| --- | --- | --- |
| 毛笔 | 泼墨弧击 · 墨浪 | **画墨台**（6.5 秒晕开褪色，画完就跑） |
| 铅笔 | 疾刺 · 掷笔 | **画永久细线**；可连通电路节点 |
| 炭条 | 粗抹 · 烟雾致盲 | **画脆台**（踩上即碎） |
| 橡皮擦 | 擦击（对素描敌×3） | **擦掉笔迹 / 纸墙 / 敌方弹幕** |
| 刮刀 | 劈砍 · 削层破甲 | **刮开厚涂墙**、削薄承重厚涂 |
| 海绵 | 挤喷水炮（左键） | **K 吸收**墨渍/水渍/墨弹蓄水（3 发） |
| 马克笔 | 标记弱点（受伤×2） | **标记「缺失像素」补全平台** |
| 剪刀 | 剪击（斩杀残血纸敌） | **剪断红色封印**放倒高墙 |
| 图章 | 敲击 | **K 盖章召唤画灵**（自动射击的同伴） |
| 荧光笔 | 弹击 · 荧光脉冲 | **画光线照明**，照出隐藏平台 |

（设计案共 24 具；原型选取了规则差异最大、最能验证系统的 10 具。携带 4 具，每关装载不同组合。）

## 实现要点

- 笔迹系统：鼠标轨迹光栅化为碰撞微盒，按工具赋予规则（褪色 / 易碎 / 永久 / 发光不碰撞 / 可被擦除）；
- 敌对笔迹（Boss 夺笔）与玩家笔迹共用几何、不同碰撞语义；
- 像素/版画×像素章 = 低清离屏缓冲混合；黑暗 = 遮罩挖洞（玩家 / 荧光笔迹 / 光点）；
- 倒影世界、重力翻转、回合制、承重崩塌、液态游泳均为关卡级 `mech` 标记驱动，便于扩充新关；
- 沿用初代七风格「单一几何、七种上墨」渲染内核 + 新增「纯白」描边画风。

## 与设计案的差异（原型裁剪）

- 24 具 → 10 具（保留规则差异最大的）；552 关 → 9 个设计案点名示例关 + Boss + 无尽模式；
- 工具熟练度成长、残章收集、排行榜未包含；「检查点更换携带」简化为每关固定装载。

初代《墨境：千面残章》七境连续世界原型在上级目录 `../mojing/`，两者共用画风渲染内核。
