# 《墨境：千面残章》· 画风侵蚀可玩原型

> 每一次转身，世界都换了一副面孔——你要在七种画风交织的战场上，用一支笔打出属于自己的风格。

这是一个**零依赖、纯前端**的 2D 横版动作原型，用 Canvas 2D 把设计案里的核心概念
「**画风侵蚀**」做成了可玩的纵向切片：世界原本是水墨手绘风，画灾之后被七种画风分区侵蚀，
每进入一个新区域，**渲染方式、敌人行为、武器形态、关卡机关、战斗手感**全部随之改变。

## 运行方式

- **直接双击 `index.html`** 即可游玩（纯静态脚本，无需构建、无需服务器）；
- 或在本目录起一个静态服务器：`python -m http.server 8000`，然后访问 `http://127.0.0.1:8000`。
- 建议用 Chrome / Edge 全屏游玩，键盘操作。

| A / D 或 ←→ | 移动 |
| 空格 / W | 跳跃（可二段跳） |

## 七境规则速览

| 境 | 画风 | 敌人 | 战斗/机关规则 |
| --- | --- | --- | --- |
| 一 · 墨渊 | 水墨 | 墨灵（悬浮扑击） | 毛笔轻击**泼墨致盲**，重击放墨浪；敌人的攻击会把墨渍晕染上屏幕，沾墨减速 |
| 二 · 泪彩 | 水彩 | 渍灵（藏在水渍里） | 敌人半透明，靠**涟漪微光**定位；重击**凝出水珠**照出并溅伤；湿润色块可**弹跳** |
| 三 · 线茧 | 素描 | 线偶（投掷捆缚线） | 炭笔轻击**擦掉它的手臂**（解除捆缚）；被线条捆住时连打方向挣脱；**橡皮重击可擦开纸墙** |
| 四 · 厚壤 | 油画 | 厚涂傀（三层色甲） | 击退无效，先用刮刀重击**削层**再造成全额伤害；厚涂墙要用刮刀**削穿开路** |
| 五 · 印坊 | 版画 | 印影（周期印出分身） | 分身一打就碎，**会呼吸的才是原版**；E 转动刻板铺桥改地形；刻痕使后续伤害×2 |
| 六 · 格庭 | 像素 | 网格哨兵（格子瞬移+点射） | 全画面降采样成低清像素；哨兵**闪白时吃像素暴击(×3)**；地形出现像素缝隙 |
| 七 · 纸原 | 剪纸 | 纸鹤兵（沿折线飞行俯冲） | 剪刀轻击可**剪断残血纸鹤**；E **折叠纸面**折出踏板；纸片剪影带裁切白边与投影 |

万化笔随画风变形：毛笔（泼墨）→ 水彩笔（凝珠）→ 炭笔（擦除）→ 刮刀（削层）→ 刻刀（雕痕）→ 激光笔（点射/光束）→ 剪刀（断折）。

## 流程内容

- 七个区域连续横版关卡（约 1.5 万 px），每境：专属敌人 + 专属机关 + 结尾「残页石龛」
  （拾取后解锁该画风残页，并展开一段「绘世者人格」的碎片故事）；
- 墨魂经济：击杀 +12、石龛 +30、缓慢自动回复；用于冲刺与残页切换；
- 终章 Boss **墨龙「未尽」**：一阶段纯水墨（墨弹 / 横扫 / 墨雨 / 召唤残念），
  半血后进入**水墨×像素混合阶段**——画面被像素块逐步污染，追加格式光柱与错误方块；
- 击败后进入结局抉择：**「融合万象」**或**「归于一墨」**，两套结局演出 + 旅行结算。

## 实现要点（供美术/程序参考）

- 单一几何、七种上墨：实体只产出路径，`Paint.fill/stroke` 按当前画风以不同笔触上墨
  （水墨双层晕边、水彩湿边、素描排线裁剪、油画厚涂高光、木刻纯黑+白凿线、剪纸投影白边）；
- 像素境 = 低清离屏缓冲（1/6 分辨率）+ `imageSmoothing=false` 放大 + 饱和度/对比滤镜；
- Boss 混合阶段 = 正常渲染之上按噪声块阵叠加像素层（`pixMix` 波动），制造「两种画风在争夺画面」的观感；
- 所有音效为 WebAudio 实时合成，无任何外部资源。

## 已知边界

- 原型不含存档与手柄支持；平衡性偏演示（Boss 900 HP，可用调试键快速跳转）；
- 若浏览器窗口比例非 16:9，画面按等比缩放留黑边。
