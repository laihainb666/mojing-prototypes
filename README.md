# 墨境：千面残章 · 两代可玩原型

「每一次转身，世界都换了一副面孔。」

本仓库收录《墨境：千面残章》IP 的两个**零依赖、纯前端 Canvas** 可玩原型。
下载任意子目录后**双击其中的 `index.html`** 即可游玩，无需构建与服务器。

| 目录 | 原型 | 核心概念 |
| --- | --- | --- |
| [`mojing/`](mojing/) | **初代 · 千面残章** | 画风侵蚀：七个连续区域，画风（水墨/水彩/素描/油画/版画/像素/剪纸）改变渲染、敌人、武器与机关；残页切换 + 墨龙 Boss + 双结局 |
| [`mojing2/`](mojing2/) | **续作 · 万具回廊** | 万具匣：10 种绘画工具（鼠标作画/擦除/召唤…），设计案 13 个点名示例关全部实现（12 章每章有实关：回合制、重力翻转、液态游泳、滚筒压印、泥浆沼泽、万象拼贴…）+ 会夺走你笔下之物的最终 Boss + 无尽回廊 |

详细说明见各目录内的 `README.md`。

## 技术要点

- 单一几何、多种上墨：实体只提供路径，由画风绘制器（水墨晕边 / 水彩湿边 / 素描排线 / 油画厚涂 / 木刻凿线 / 像素降采样 / 剪纸投影 / 纯白描边）分别上墨；
- 全部音效为 WebAudio 实时合成，无任何外部资源；
- 关卡机关由声明式 `mech` 标记驱动，便于扩充。

两个原型共用同一套画风渲染内核（`js/styles.js` / `render.js` 的前身与现役）。
